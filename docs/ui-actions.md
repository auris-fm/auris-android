# Auris UI Actions

Complete reference of every user-facing action available through the app's UI, organized by category.

---

## Playback Control

### Transport

| Action | How |
|--------|-----|
| Play / Pause | Tap play/pause button on player, notification, widget, or lock screen |
| Skip forward | Tap skip-forward button (default 30 s); long-press to change skip duration |
| Skip backward | Tap skip-backward button (default 15 s); long-press to change skip duration |
| Seek to position | Drag the progress bar on the player screen |
| Skip to next episode | Tap next-episode button on player or in Up Next |
| Mark as played | Tap "Mark as played" in episode actions or player shelf |
| Mark as unplayed | Tap "Mark as unplayed" in episode multi-select |

### Speed & Effects

| Action | How |
|--------|-----|
| Open effects panel | Tap effects icon on player shelf or toolbar |
| Set playback speed | Adjust speed slider in effects panel (0.5×–5.0×) |
| Trim silence | Toggle trim-silence mode (off / low / medium / high) in effects panel |
| Volume boost | Toggle volume boost in effects panel |
| Apply to all podcasts or one | Switch between "All Podcasts" and "This Podcast" tabs in effects panel |
| Save effects | Tap save in effects panel |

### Sleep Timer

| Action | How |
|--------|-----|
| Open sleep timer | Tap sleep icon on player shelf |
| Set timer (minutes) | Choose duration (5 / 10 / 15 / 30 / 45 / 60 / 90 / 120 min) |
| Sleep at end of episode | Tap "End of episode" |
| Sleep at end of chapter | Tap "End of chapter" |
| Add extra time | Tap "+" while timer is running |
| Cancel timer | Tap cancel / "End of chapter" again |

### Chapters

| Action | How |
|--------|-----|
| Open chapters list | Tap chapter title on player |
| Play a chapter | Tap a chapter row |
| Tap chapter link | Tap a linked URL in the chapter row |

### Video

| Action | How |
|--------|-----|
| Enter full screen | Tap full-screen icon in player toolbar |
| Enter PiP | Tap PiP icon in player toolbar |

## Up Next Queue

| Action | How |
|--------|-----|
| Add episode to top of queue | Tap "Play Next" in episode actions, or swipe right (first position) |
| Add episode to bottom of queue | Tap "Play Last" in episode actions, or swipe right (second position) |

| Reorder episode | Long-press drag in Up Next list |

| Multi-select in Up Next | Long-press an episode to enter multi-select |

## Episode Chat (AI Assistant)

Plus feature. Opened from episode detail screen via "Episode chat" banner.

| Action | How |
|--------|-----|
| Open chat | Tap "Episode chat" banner row on episode detail, or tap compact ChatBanner near the transcript card |
| Type message | Enter text in chat input bar |
| Send message | Tap send button or press keyboard Send |

| Open options | Tap three-dot menu in chat toolbar |
| Clear chat | Tap "Clear chat" in options dialog |
| Close chat | Tap back arrow or swipe dismiss |
| Open paywall (non-Plus) | Tap "Episode chat" banner — shows paywall dialog instead of chat |
| Subscribe from paywall | Tap "Start free trial" or "Subscribe to Plus" button on paywall |
| Dismiss paywall | Tap X on paywall dialog |

## Swipe Actions (Episode Lists)

Swipe gestures are configurable per screen. Default layout:

**Left-to-right swipe** (up to 2 positions):

| Position | Default Action |
|----------|----------------|
| 1st | Play Next (add to top of Up Next) |
| 2nd | Play Last (add to bottom of Up Next) |

**Right-to-left swipe** (up to 3 positions):

| Screen | Position 1 | Position 2 | Position 3 |
|--------|-----------|-----------|-----------|
| Podcast episodes | Archive | Share | Add to playlist |
| User episodes | Delete | — | — |
| Up Next | Move to top | Move to bottom | — |
| Smart playlist | Archive | Share | Add to playlist |
| Manual playlist | Remove from playlist | Archive | Share |
